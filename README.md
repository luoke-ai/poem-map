# 古诗地图

把中小学课本里背过的古诗词，一条一条标到真实地图上。点开每一首诗，看到的是：原诗全文、这句诗写在今天哪个地方、以及「诗里」与「今地」的对照。

在线访问：**https://luoke-ai.github.io/poem-map/**

## 里面有什么

- **56 首诗 · 59 处地点 · 7 个区域**（唐 40、宋 14、元 1、汉 1；另有 3 篇文、1 首四言）
- 区域分片：江南 14、江淮赣皖 11、关中河东 10、荆楚 7、巴蜀 7、塞外边地 5、岭海 2
- 每一首包含：题目 / 作者 / 朝代 / 体裁 / 学段、名句、原诗（可切竖排）、「这是哪里」、诗与今对照、「今地坐标」卡片
- 同一首诗涉及多地时（渭城+阳关、夔州+朗州、长安+蒲州），地图上用虚线把几个点连起来
- **9 处标注「地点存疑」**：如「二十四桥」「巴山楚水」「碣石」「幽州台」「陋室」，正文里写清各家的说法与分歧，不装作有定论

几个例子：

- 「二十四桥明月夜」→ 扬州瘦西湖二十四桥。今桥为 1990 年代重建，长 24 米、宽 2.4 米、24 级台阶；唐代原桥何在无定论（沈括《梦溪笔谈》记扬州有二十四桥，李斗《扬州画舫录》则指吴家砖桥／红药桥）。
- 「巴山楚水凄凉地」→ 两个点：巴山即夔州（今重庆奉节），楚水即朗州（今湖南常德）。刘禹锡自 805 年贬出，至 826 年扬州席上遇白居易，故云「二十三年」。
- 「夜半钟声到客船」→ 苏州枫桥与寒山寺，今天仍隔一条运河相望。

## 怎么做的

纯静态页面，没有构建步骤，也不依赖任何框架：

- 地图用本地打包的 [Leaflet](https://leafletjs.com/) 1.9.4
- 底图用高德地图栅格瓦片（GCJ-02 坐标系）。数据按 WGS-84 存储，运行时由 `app.js` 里的 `wgs2gcj()` 转换，所以标注位置与底图对得上
- 低缩放级别下按屏幕距离聚类，聚合点显示「N 首」；点开后是当前视野内这一簇诗的清单
- 样式走宣纸 / 墨字 / 朱砂印的路子：底 `#f2ebde`，字 `#211d1a`，印 `#b0442f`，宋体字族；竖排开关给原诗用

## 文件

```
index.html    页面骨架（地图、右侧索引、详情浮层）
style.css     全部样式，含移动端底部抽屉
data.js       诗库：window.POEMS，56 条，每条含原诗、名句、地点与对照
app.js        地图初始化、坐标转换、聚类、列表渲染、详情渲染
leaflet/      Leaflet 1.9.4（本地打包，不依赖 CDN）
```

想加一首诗，只改 `data.js` 即可，页面上的计数、区域筛选、搜索都是自动生成的。

## 说明

诗句与地名考据据公开文献（史书、地方志、诗集笺注、地名志）整理，坐标为写实地的大致位置，供阅读与联想之用，不作测绘依据。凡有争议的地点，条目内均已注明「地点存疑」及各家说法。
